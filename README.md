## The four rules

1. **XP requires an artefact.** Reading and watching score zero. A committed file,
   a passing test or a cleared boss fight scores.
2. **Write first, review second.** Any quest where an assistant wrote the first
   draft scores zero.
3. **The streak is sacred.** One kata most days, fifteen minutes minimum.
4. **Speedrun the early levels.** Take each skip test honestly. Levels 1 to 3
   should be weeks, not months.

python-quest/

Each level folder has its own README listing that level's quests. Tick them there
as you go, then roll the totals up into this page on Sunday.
