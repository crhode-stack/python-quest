# Katas

One small problem, fifteen minutes, most days. 15 XP each.

The streak multiplier is the biggest XP lever in the game and the only one
that compounds. Seven days gives x1.2, twenty-one days x1.5, fifty days x2.0.

## Where to get them

- Exercism's Python track, and **request a mentor review on every one**.
  Free, human, and the mentors are ruthless about idiom.
- Python Morsels (paid). The written explanations of every alternative
  solution are the real product.
- Advent of Code archives.
- A single function pulled out of whatever you are currently building.

## Filing

One file per kata, named `YYYY-MM-DD-short-name.py`. Commit it the same day.
An uncommitted kata did not happen.
